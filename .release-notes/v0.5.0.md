Graph navigation now follows a predictable interaction model. Drag the canvas
to pan in any direction; clicking a node selects it, and nodes stay in their
automatic layout. Selecting a node or opening its detail panel keeps the current
view in place.

The page-level Zoom in and Zoom out controls now change zoom as labelled. Fit
returns the current graph to a centered overview, and Reset clears selection
and filters before fitting the graph. Viewport controls have accessible names
for assistive technology.
