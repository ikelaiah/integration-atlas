This release adds a DocSprout-powered documentation site and a guided Northstar walkthrough for tracing how a source change affects downstream integrations.

- DocSprout builds a searchable site from the README and selected `docs/` pages.
- The walkthrough explains how to load the synthetic estate, trace `StudentID`, and inspect the evidence behind a relationship.
- Scanning remains local and static. Atlas does not execute discovered files, upload estate data, or require an Atlas scanning agent.
- Install the CLI from a checkout with `python -m pip install -e .` (Python 3.11 or newer). Build the web interface with `npm --prefix frontend ci` and `npm --prefix frontend run build` (Node.js 22 or newer); Docker remains optional.
- Existing SQLite databases upgrade on startup through idempotent, data-preserving migrations.
- Current limits: discovery covers the documented file formats and uses static analysis; it does not observe runtime traffic.
- Report vulnerabilities through [the security policy](https://github.com/ikelaiah/integration-atlas/blob/main/SECURITY.md).
