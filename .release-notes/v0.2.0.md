This release makes discovered integration maps easier to verify and correct before using them for impact analysis.

- Preview additions, updates and retirements before applying a scan. Preview leaves the workspace unchanged; apply saves the actual diff in scan history.
- Inspect relationship evidence in a review queue, then confirm or reject a proposal with an optional redacted note. Verdicts survive rescans.
- Edit descriptive entity fields in the Atlas detail panel. Manual corrections survive rescans.
- Scan history now loads the progress and diff data expected by the web UI.
- The local Northstar example and [review workflow](https://ikelaiah.github.io/integration-atlas/review-workflow.html) show these features in action. GitHub Pages hosts documentation; the interactive Atlas app runs locally and does not require a scanning agent.
- Existing SQLite databases upgrade without data loss. Scans remain static and local; they do not execute source files or observe runtime traffic.
