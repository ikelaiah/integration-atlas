This release makes large integration maps easier to navigate and share.

- Combine stable entity type, environment, confidence, relationship type, review status and text filters. Filter counts continue to describe the full active workspace while the view narrows.
- Find paths across the whole workspace, including entities hidden by graph filters. Atlas shows the exact route on the graph and explains whether influence flows downstream, upstream or only through mixed directions.
- Download the filtered graph as Mermaid or PlantUML from the Atlas web interface, or export the full active, non-rejected graph with `atlas export -f mermaid|plantuml`.
- Diagram labels are redacted and escaped. Exports report node and edge counts, respect graph limits and require no remote service or scanning agent.
- The [navigation and sharing guide](https://ikelaiah.github.io/integration-atlas/navigation-and-sharing.html) shows the Northstar workflow. Existing SQLite data and JSON, CSV and GraphML exports remain compatible.
