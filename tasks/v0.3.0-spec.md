# Specification: v0.3.0 Navigate and Share

## Objective

Make a large integration graph easier to narrow, trace, and share. Operators can
combine stable graph filters, find a path between any active workspace entities,
understand whether it follows or opposes influence, and export the selected view
as Mermaid or PlantUML text. Atlas remains local and scanners remain static.

## User flows

1. Open Atlas and combine entity type, environment, minimum confidence,
   relationship type, review status, and text search filters. Choices remain
   available while filters are active. Counts describe the full active workspace
   so the operator understands the effect of narrowing the view. Clear all
   returns to the default graph; rejected relationships stay hidden by default.
2. Open Find path and search the whole active workspace, even if the current
   graph is filtered or truncated. Pick two distinct entities, swap them, and
   inspect the shortest path. The result says whether it is downstream,
   upstream, or only connected through mixed directions. Empty and error states
   are distinct. Each step identifies its relationship and confidence.
3. Export the graph currently selected by the filters as Mermaid or PlantUML
   from the Atlas toolbar. The downloaded text has stable IDs, escaped labels,
   visible node and edge counts, and no rejected edges unless explicitly
   selected. The CLI supports the same formats for an unfiltered workspace.

## API and data contract

- Extend `GET /api/graph` with `relationship_type[]`, `review_status[]`, and
  `q`. Existing entity type, environment, and confidence filters remain.
- Return unfiltered facet counts for entity type, environment, relationship
  type, and review status alongside the bounded graph result.
- `GET /api/graph/export?format=mermaid|plantuml` accepts the same filters and
  graph limit, returning UTF-8 plain text as an attachment. It exports the
  same bounded node and edge set as `GET /api/graph`.
- `GET /api/path` returns `mode` (`downstream`, `upstream`, `connected`, or
  `none`) with its existing path details. The path ignores visual filters.
- `atlas export -f mermaid|plantuml -o FILE` writes the active, nonrejected
  graph. Existing JSON, CSV, and GraphML formats remain compatible.

## Safety and performance

- Diagram labels are redacted and escaped, with no source snippets or evidence.
- Downloads contain no browser secrets and are generated from the local API.
- Graph and export limits are bounded; truncation is explicit in the UI and
  exported diagram. Search uses existing active graph rows.
- No database migration, remote service, agent, or source file execution.
